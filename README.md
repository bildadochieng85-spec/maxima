# Maximall

The storefront includes product search and department filters, product detail pages, saved items, a cart, checkout, payment simulation, sign-in, signup, and an account dashboard.

## Run locally

Requires Node.js 18 or newer.

```sh
npm install
npm run dev
```

Create and preview a production build:

```sh
npm run build
npm run preview
```

The Vite build copies the product images into `dist`. Client-side navigation uses hash routes, so direct links and browser history work without additional server rewrite rules.
